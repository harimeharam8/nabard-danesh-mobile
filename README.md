# نبرد دانش‌آموزی — نسخه موبایل آفلاین

این یک پروژه آغازین Flutter برای اندروید و iOS است. سؤال‌ها در فایل `assets/questions/questions.json` قرار دارند؛ برای بازی‌کردن اینترنت لازم نیست.

## امکانات فعلی
- مسابقه چهارگزینه‌ای
- فیلتر بر اساس پایه هفتم، هشتم و نهم و درس
- نمایش پاسخ درست و توضیح کوتاه
- ذخیره امتیاز و تعداد پاسخ‌ها داخل گوشی
- تهیه نسخه پشتیبان JSON از پیشرفت و سؤال‌ها
- بازیابی پیشرفت از فایل پشتیبان JSON

## پیش‌نیاز
Flutter SDK نصب باشد و دستور `flutter doctor` بدون مشکل اساسی اجرا شود. برای ساخت iOS به macOS و Xcode نیاز دارید؛ ساخت فایل iOS روی ویندوز به‌تنهایی ممکن نیست. ساخت APK اندروید روی ویندوز امکان‌پذیر است.

## اجرا
در پوشه پروژه:

```bash
flutter pub get
flutter run
```

## ساخت نسخه اندروید
```bash
flutter build apk --release
```
خروجی معمولاً در مسیر `build/app/outputs/flutter-apk/app-release.apk` ساخته می‌شود.

## ساخت نسخه iOS
روی Mac:
```bash
flutter build ios --release
```
برای نصب و انتشار iOS، تنظیمات امضای اپل و Xcode لازم است.

## افزودن سؤال
فایل `assets/questions/questions.json` را باز کنید و یک شیء جدید با همین ساختار اضافه کنید:

```json
{
  "id": "science-003",
  "grade": "هفتم",
  "subject": "علوم",
  "question": "متن سؤال",
  "options": ["گزینه ۱", "گزینه ۲", "گزینه ۳", "گزینه ۴"],
  "answer": 0,
  "explanation": "توضیح پاسخ"
}
```

نکته: `answer` شماره گزینه صحیح از صفر است؛ `0` یعنی گزینه اول و `3` یعنی گزینه چهارم. شناسه `id` هر سؤال باید یکتا باشد.

## محدودیت‌های نسخه آغازین
- این نسخه مسابقه آنلاین یا چندنفره ندارد؛ کاملاً آفلاین است.
- سؤال‌های نمونه صرفاً برای آزمایش هستند و قبل از استفاده آموزشی جدی باید بازبینی شوند.
- بازیابی نسخه پشتیبان فعلاً پیشرفت بازیکن را بازیابی می‌کند؛ فهرست سؤال‌ها در این نسخه از فایل داخل برنامه بارگذاری می‌شود.
